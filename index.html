い形容詞 — Adjectifs en -i

La racine s'obtient en retirant le い final. Exemple avec 大きい (ōkii — grand).

FormeTransformationExempleTraduction
Présent aff. tel quel 大きい C'est grand
Présent nég. い → くない 大きくない Ce n'est pas grand
Passé aff. い → かった 大きかった C'était grand
Passé nég. い → くなかった 大きくなかった Ce n'était pas grand
Forme て い → くて 大きくて (liaison entre phrases)
Devant un nom tel quel — rien à ajouter 大きい部屋 grande pièce
大きい犬がいます。 （おおきいいぬがいます） Il y a un grand chien.
⚠️ Exception : いい → se conjugue comme よい
よくない pas bien ✓
いくない ✗ incorrect
よかった c'était bien ✓
いかった ✗ incorrect

な形容詞 — Adjectifs en -na

Exemple avec きれい (kirei — beau, propre).

FormeTransformationExempleTraduction
Présent aff. + だ / です きれいです C'est beau
Présent nég. + じゃない きれいじゃない Ce n'est pas beau
Passé aff. + だった きれいだった C'était beau
Passé nég. + じゃなかった きれいじゃなかった Ce n'était pas beau
Forme て + で きれいで (liaison entre phrases)
Devant un nom + な — OBLIGATOIRE ! きれいな部屋 belle pièce
きれいな花があります。 （きれいなはながあります） Il y a de jolies fleurs. ← な avant le nom
この花はきれいです。 （このはなはきれいです） Cette fleur est belle. ← prédicat : pas de な

⚠️ Les adjectifs pièges

Ces adjectifs finissent par un son -i ou -ki mais sont des な形容詞 — on doit quand même ajouter な devant un nom !

きれい な
綺麗 — beau, propre
✓ きれいな部屋 ✗ きれい部屋
きれいな部屋ですね。
C'est une belle chambre.
きらい な
嫌い — détester
✓ きらいな食べ物 ✗ きらい食べ物
きらいな食べ物は何ですか？
Qu'est-ce que tu n'aimes pas manger ?
ゆうめい な
有名 — célèbre
✓ ゆうめいな人 ✗ ゆうめい人
有名な歌手が来ます。
Un chanteur célèbre vient.
すき な
好き — aimer
✓ すきな食べ物 ✗ すき食べ物
好きな音楽は何ですか？
Quelle musique tu aimes ?
すてき な
素敵 — superbe
✓ すてきな服 ✗ すてき服
素敵な服ですね。
Ce sont de beaux habits.
げんき な
元気 — en forme
✓ げんきな子供 ✗ げんき子供
元気な子供ですね。
C'est un enfant plein d'énergie.
